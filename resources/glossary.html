🖥️ Hardware & Computing (21)

CPU Central Processing Unit

The computer's main processor — it carries out the instructions of every program you run, from your game engine to your web browser. Measured in GHz (clock speed) and number of cores. A faster CPU means your engine compiles code and runs game logic more quickly.

🖼️ Show diagram

GPU Graphics Processing Unit

A specialised processor built to render images, especially the millions of triangles and pixels in a 3D game scene. A dedicated GPU is the single most important spec for real-time 3D rendering — it's why “recommended requirements” for Unreal and Unity always list one.

🖼️ Show diagram

RAM Random Access Memory

Fast, temporary working memory. Your operating system, engine and every open program share it while running — when it fills up, everything slows down. Unlike storage, RAM is wiped every time the computer restarts.

🖼️ Show diagram

Storage (SSD & HDD)

Where files are kept permanently, even with the power off. An SSD (Solid State Drive) has no moving parts and is much faster than an HDD (Hard Disk Drive), which uses a spinning magnetic disk. Project files, builds and asset libraries all live here.

🖼️ Show diagram

Motherboard

The main circuit board that everything else plugs into — CPU, RAM, storage and graphics card all connect to it, letting them communicate with each other.

🖼️ Show diagram

PSU Power Supply Unit

Converts mains electricity into the specific voltages every component needs. Under-sized for a build with a demanding GPU, and the whole system can crash or fail to boot — this is why gaming PC builds always list a wattage.

🖼️ Show diagram

Peripheral

Any device connected to a computer that isn't part of the core system itself — keyboard, mouse, monitor, controller, microphone, drawing tablet. “Input” peripherals send information in; “output” peripherals (like monitors and speakers) send information out.

OS Operating System

The core software that manages hardware and runs everything else — Windows, macOS and Linux are the three you'll meet most. Your game engine, and every file you save, ultimately runs on top of the OS.

Resolution

The number of pixels that make up an image or screen, written as width × height (e.g. 1920×1080). Higher resolution means more detail — and more work for the GPU to render each frame.

🖼️ Show diagram

Aspect Ratio

The proportional relationship between a screen's width and height, such as 16:9 (widescreen, the standard for modern monitors and TVs) or 4:3 (older, more square displays). Design your game's UI and camera around the aspect ratio it will actually be played at.

🖼️ Show diagram

Refresh Rate

How many times per second a monitor redraws the image, measured in Hertz (Hz). A 60Hz monitor refreshes 60 times a second — even a game running at 200 frames per second won't look any smoother than that on a 60Hz screen.

FPS Frames Per Second

How many complete images your game draws every second. 30 FPS is a common minimum for smooth-feeling gameplay; 60 FPS feels noticeably more responsive. If FPS drops sharply during play, something in your scene is too expensive for the hardware to render in time.

🖼️ Show diagram

USB Universal Serial Bus

The standard connector for plugging almost anything into a computer — keyboards, mice, controllers, external drives. “USB-A” is the classic rectangular plug; “USB-C” is the newer reversible oval one.

🖼️ Show diagram

HDMI High-Definition Multimedia Interface

The standard cable and port for sending video and audio from a computer or console to a monitor or TV in a single cable.

🖼️ Show diagram

Controller / Gamepad

A handheld input peripheral with buttons, sticks and/or a d-pad, used to play games on consoles and PCs as an alternative to keyboard and mouse.

🖼️ Show diagram

Bit & Byte

A bit is the smallest unit of digital information — a single 0 or 1. A byte is 8 bits grouped together. File sizes (KB, MB, GB) are all built from bytes: a kilobyte is roughly 1,000 bytes, a gigabyte roughly 1,000 megabytes.

Bandwidth

How much data can move through a connection in a given time — like how many lanes are on a highway. Low bandwidth is why large downloads (a big game build, a video export) can take a long time even on a fast computer.

Cache

A small pocket of very fast, temporary storage that keeps recently-used data close at hand so it doesn't have to be fetched again from somewhere slower. Browsers, engines and CPUs all use caches to speed things up.

Cloud Storage

Storing files on remote servers over the internet (like OneDrive or Google Drive) instead of only on your own device. It backs up your work automatically and lets you access it from any computer — exactly why this course asks you to keep your project files there.

Driver & Firmware

A driver is software that lets your operating system talk to a piece of hardware (like a graphics card or printer). Firmware is low-level software built into a device itself — your motherboard's BIOS is a classic example.

Malware

Malicious software designed to damage, disrupt or gain unauthorised access to a computer — viruses, ransomware and spyware are all types. Downloading game assets or tools only from trusted sources is one of the simplest ways to avoid it.

💾 File Formats & Data (9)

File Extension

The letters after the dot in a filename (.docx, .png, .unity) that tell the operating system — and you — what kind of file it is and which program should open it.

.PNG Portable Network Graphics

A lossless image format that supports transparency (an alpha channel) — the standard choice for game sprites, icons and UI elements, since edges stay crisp and backgrounds can be see-through.

.JPG / .JPEG Joint Photographic Experts Group

A compressed, lossy image format ideal for photos, but a poor choice for sprites — it has no transparency and can blur sharp pixel-art edges.

.WAV Waveform Audio File Format

An uncompressed, lossless audio format. Larger file size than MP3, but no quality lost — the right format to record and edit sound effects in before exporting a compressed version.

.MP3 MPEG Audio Layer 3

A compressed, lossy audio format that trades a little quality for a much smaller file size — the standard choice for shipping music and voice in a finished game build.

.PSD & .AI

.PSD is Adobe Photoshop's native, layered file format — the editable “source” for a piece of raster (pixel-based) artwork. .AI is Adobe Illustrator's native format for vector (scalable, path-based) artwork. Keep these as your working files and export flat .png/.jpg copies for actual use in-game.

.DOCX, .XLSX & .PPTX

Microsoft's native file formats for Word documents, Excel spreadsheets and PowerPoint presentations. The “x” shows they're the modern, XML-based versions of the older .doc/.xls/.ppt formats.

Compression (Lossy vs Lossless)

Shrinking a file's size. Lossless compression (like .png or .wav) loses no information — you can always get the original back. Lossy compression (like .jpg or .mp3) permanently discards some detail to save space, which is fine for shipping but risky for an editable source file.

Metadata

Data about data — information attached to a file that describes it rather than being its actual content, like when a photo was taken, or who created a document and when.

🎨 Game Design Concepts (19)

GDD Game Design Document

The reference document that defines what a game is — its concept, mechanics, story, art direction, levels and technical scope — written before (and updated during) development so everyone building the game is working from the same plan.

Core Mechanic

The one action the player repeats more than any other — jumping in a platformer, matching in a puzzle game, aiming in a shooter. Everything else in the design usually exists to support or vary the core mechanic.

Genre

A category of game defined by its mechanics and player experience rather than its setting — platformer, puzzle, tower defence, endless runner. Knowing your genre's conventions tells you what players will already expect.

Prototype

A rough, early, playable version of a game or mechanic built to test whether an idea is actually fun — not polished, not final, built to be reworked or thrown away.

Playtesting

Watching someone else play your game to see where it works and where it doesn't — usually far more revealing than playing it yourself, since you already know how it's “supposed” to be played.

Iteration

The repeating cycle of designing, testing and improving. Very few games are good on the first attempt — iteration is how a rough prototype becomes a finished game.

Game Loop

The core cycle every real-time game runs, many times per second: read player input, update the game's state (physics, AI, logic), then render the result to the screen — then repeat.

🖼️ Show diagram

Win / Lose Condition

The specific rule that ends a level or game — reaching a goal, running out of health, beating a timer. Without a clear win or lose condition, a player has no way to know how they're doing.

Difficulty Curve

How a game's challenge changes over time. A well-designed curve ramps up gradually, teaching new skills before demanding them, rather than spiking suddenly and frustrating the player.

Balance

Making sure no single strategy, weapon or character is so strong (or so weak) that it breaks the intended challenge or fairness of a game.

Level Design

The craft of building the actual spaces a player moves through — laying out obstacles, pacing challenge, guiding attention, and controlling the flow of a level from start to finish.

HUD Heads-Up Display

The on-screen information layered over gameplay — health bars, score, ammo count, a minimap — that the player can read without leaving the action.

🖼️ Show diagram

UI & UX User Interface / User Experience

UI is what the player sees and interacts with — menus, buttons, HUD. UX is the broader experience of how easy, clear and satisfying that interaction actually feels. Good UI can still have bad UX if it's confusing to use.

NPC Non-Player Character

Any character in a game that isn't controlled by a human player — an enemy, a shopkeeper, a background crowd member. Their behaviour is driven by the game's code (or, in more advanced games, AI).

Checkpoint

A saved point in a level that a player returns to after failing, so they don't have to replay everything from the very start.

Power-Up

A temporary or permanent boost a player collects during play — extra speed, a shield, a stronger weapon.

High-Concept Pitch

A one-sentence description of a game that anchors it to something familiar plus a twist — e.g. “It's like Mario Kart, but every kart is a shopping trolley.” Useful for explaining an idea instantly.

MVP Minimum Viable Product

The smallest version of a game that still counts as “done” — the essential features needed to be playable and demonstrate the idea, with everything else treated as a stretch goal.

Stretch Goal

A feature or improvement you'd like to add if time allows, planned for after the MVP is complete — never built at the expense of the essentials.

🛠️ Engines & Development (12)

Game Engine

Software that provides the common building blocks every game needs — rendering, physics, input, audio — so developers don't have to write them from scratch. Unity, Unreal Engine and GameMaker Studio 2 are the three used in this course.

Sprite

A single 2D image used to represent a character, object or effect in a game — the basic visual building block of 2D games.

🖼️ Show diagram

Spritesheet & Tileset

A spritesheet packs multiple sprites (like the frames of a walking animation) into one image. A tileset does the same for level-building pieces — floors, walls, decorations — arranged in a grid so an engine can slice and reuse them to build a whole level from a handful of tiles.

🖼️ Show diagram

Hitbox & Collision Detection

A hitbox is the (often invisible) shape an engine uses to detect when something touches something else — usually simpler than the visible sprite it's attached to. Collision detection is the engine constantly checking whether any hitboxes overlap, which is how it knows a player has hit a wall, collected a coin, or been hit by an enemy.

🖼️ Show diagram

Scene / Room

A single, self-contained space in a game — one level, one menu screen — holding all the objects, layout and logic for that space. Unity calls these “scenes”; GameMaker Studio 2 calls them “rooms”.

Asset

Any individual piece of content used to build a game — a sprite, sound effect, music track, 3D model or font.

Blueprint (Unreal)

Unreal Engine's visual scripting system — building game logic by connecting nodes on screen instead of writing text-based code.

GML GameMaker Language

The programming language built into GameMaker Studio 2 for writing custom game logic beyond what the drag-and-drop tools offer.

Build

A compiled, runnable version of a game exported from the engine — the actual playable file (or folder of files) you'd send to a tester or upload to itch.io.

Debug & Bug

A bug is any part of a program that doesn't behave the way it's supposed to. To debug is to find and fix it — usually by reproducing it reliably, then working out exactly what's causing it.

Version Control

A system (like Git) for tracking changes to files over time, so you can see what changed, when, and roll back to an earlier version if something breaks. Even a simple dated-folder habit or OneDrive's version history is a basic form of it.

Frame (Animation)

One single image in a sequence that, played quickly one after another, creates the illusion of movement — the same principle as a flipbook.

🏢 Industry & Production (11)

Indie & AAA

Indie (“independent”) games are made without a big publisher's funding, usually by small teams or solo developers. AAA (“triple-A”) games are big-budget titles made by large studios with major publisher backing.

Publisher & Developer

The developer is the studio (or person) that actually builds a game. The publisher funds, markets and distributes it — sometimes the same company does both.

Alpha & Beta

An alpha build has the core features in place but is rough and likely unstable — for internal testing. A beta build is more complete and polished, often released to a wider group of testers before final launch.

Early Access

Selling and releasing an unfinished game to the public, who can play (and often give feedback on) it while it's still being developed.

Port

Adapting a game originally built for one platform (say, PC) so it runs on another (like a console or mobile) — often requiring changes to controls, performance and UI.

DLC & Mod

DLC (Downloadable Content) is extra official content released after a game's launch — new levels, characters or story. A mod (“modification”) is unofficial content created by players themselves, changing or adding to the original game.

Esports

Competitive video gaming played at an organised, spectated level — tournaments, leagues, and professional or semi-professional players.

Stakeholder

Anyone affected by, or with an interest in, a project's outcome — for your major project, that includes you, your teacher, your testers, and the people who'll eventually play your game.

Gantt Chart

A project-scheduling chart where each row is a task and each bar shows when it starts and finishes against a timeline — the standard way to plan and track a multi-week project.

🖼️ Show diagram

SMART Goal Specific, Measurable, Achievable, Realistic, Time-referenced

A goal written precisely enough that you can tell, objectively, whether you've met it — e.g. “implement player jump with variable height by the end of Week 6”, rather than a vague “make the game feel good”.

Work Requirement

A specific, mandatory deliverable set by a TASC course that must be completed to be eligible for an award — regardless of how well everything else was done. PRJ205118's Major Project has six of these.

⚖️ Digital Citizenship & Legal (8)

Copyright

Legal protection that exists automatically the moment an original creative work — art, music, code, writing — is created. You cannot use someone else's copyrighted work in your game without permission, even if you found it free online.

Creative Commons CC0, CC BY, CC BY-NC, etc.

A set of standard licences creators can attach to their work to say exactly how others may use it — from CC0 (no restrictions at all) to CC BY-NC (free to use non-commercially, with credit). See the full breakdown on the Research & References page.

IP Intellectual Property

Creations of the mind that the law treats as ownable property — designs, inventions, music, code and art all count. Copyright is one of the main legal tools that protects it.

Attribution

Publicly crediting the original creator of a work you've used — usually required by Creative Commons “BY” licences, and simply good practice even when it isn't.

Public Domain

Work with no copyright restrictions at all, either because the copyright has expired or the creator has waived it — free for anyone to use for any purpose. Being findable on the internet does NOT make something public domain.

AUP Acceptable Use Policy

The rules a school (or workplace) sets for how its computers, network and internet access may be used — covering things like personal use, monitoring, and consequences for misuse.

OH&S Occupational Health and Safety

Practices and rules that protect people from harm at work or in a lab — for a computer classroom, that includes ergonomics, cable management, and safe use of equipment.

E-Waste Electronic Waste

Discarded electronic devices and components — old computers, phones, cables. Improperly disposed e-waste can release toxic materials, which is why it needs specific recycling processes rather than going in general rubbish.
